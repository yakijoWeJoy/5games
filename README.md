# דף ועיפרון ✏️

חמשת משחקי הדף והעיפרון שלנו, כל אחד בטלפון שלו, מסונכרנים:

1. **בול פגיעה** – כל אחד בוחר קוד סודי של 4 ספרות שונות. מי שפותח מקבל אותו מספר תורות כמו השני, כך שלשני יש הזדמנות אחרונה להשוות.
2. **איש תלוי** – כל אחד בוחר מילה (עברית או אנגלית) ואפשר להוסיף רמז. אות נכונה = עוד תור. אפשר גם לנחש את כל המילה. 10 טעויות = נתלית.
3. **צוללות** – לוח 6×6 עם צוללות בגודל 2, 3, 4 וצוללת ן (5 משבצות). אסור שצוללות ייגעו זו בזו, גם לא באלכסון. פגיעה = עוד תור. אחרי טביעה, המשבצות שמסביב מסומנות אוטומטית.
4. **נקודות** – 6×6 נקודות. מי שסוגר ריבוע מקבל אותו ועוד תור.
5. **5 בשורה** – דף משבצות ענק (21×21). הראשון שמשלים 5 ברצף מנצח.

### הסדרה – הטוב מחמישה
- משחקים את חמשת המשחקים לפי הסדר, בלי לדלג.
- אחרי כל משחק אפשר **משחק חוזר** (התוצאה נמחקת ומשחקים אותו שוב).
- מי שמגיע ל-3 ניצחונות ניצח את הסדרה; אם זה קרה לפני המשחק החמישי – אפשר להמשיך עד הסוף בשביל הספורט.
- אפשר להתחיל **סדרה חדשה** בכל שלב. סדרה שהוכרעה או הסתיימה נרשמת בטבלת "סדרות הערב".
- מי שפותח כל משחק מתחלף ממשחק למשחק ומסדרה לסדרה.

### של מי התור?
"העיפרון עובר מיד ליד": כשתורך – מסגרת בצבע העט שלך סביב המסך, פס "תורך" מודגש, צליל קצר, ושם הלשונית מתחלף ל-"✏️ תורך!". כשלא תורך – הלוח מתעמעם מעט וכתוב מי חושב עכשיו. בכותרת יש ✏️ ליד מי שתורו, וכפתור 🔔 להשתקה.

### איך משחקים?
בפעם הראשונה שמשחקים משחק בטלפון, נפתח כרטיס קצר עם החוקים וכפתור "הבנתי". אחר כך הוא לא קופץ שוב, אבל תמיד אפשר לפתוח אותו עם ה-? בפס התור.

יש גם כפתור **פתק** לשליחת הודעות קצרות – אבל הכי כיף לשחק כשיושבים יחד, או מדברים בטלפון תוך כדי.

## איך משחקים
1. טלפון אחד: נכנסים לאתר ובוחרים **"פותחים דף חדש"**. מקבלים קוד של 4 ספרות.
2. טלפון שני: פותחים את קישור ההזמנה (וואטסאפ או שיתוף), או מקלידים את הקוד.
3. בוחרים משחק מהרשימה ומשחקים.

### איך הטלפונים מתחברים
כל הודעה נשלחת במקביל בכמה ערוצים, והצד השני מסנן כפילויות:
- **שרתי תיווך** – שלושה שרתי MQTT ציבוריים (EMQX, HiveMQ, Mosquitto) דרך WebSocket מאובטח. עובד גם כששני הטלפונים בגלישה סלולרית ולא יכולים להגיע ישירות זה לזה.
- **קו ישיר** – WebRTC דרך [PeerJS](https://peerjs.com/), כשהרשת מאפשרת.

מספיק שערוץ אחד עובד. אין שרת משלנו ואין הרשמה. הטלפון שפתח את הדף שומר את המצב, כך שאם הדף נטען מחדש או החיבור נופל – המשחק ממשיך מאותה נקודה. מסך הטלפון נשאר דלוק בזמן המשחק.

### לוגים מרכזיים
כל טלפון שולח יומן טכני קצר (שלבי חיבור, שגיאות, איזה מסך ואיזה כפתור) לנושא ב-[ntfy.sh](https://ntfy.sh). בלי שמות, בלי תוכן הפתקים, בלי קודים סודיים ומילים. הלוגים נשמרים כ-12 שעות.
```
tools/logs.sh            # 12 השעות האחרונות, כל המכשירים
tools/logs.sh 2h ab3k9   # שעתיים אחרונות, מכשיר מסוים (המזהה מופיע תחת "משהו לא עובד?")
```
שם הנושא כתוב בקוד, והמאגר ציבורי – כלומר מי שמחפש יכול לקרוא את היומן הטכני הזה.

### נתוני שימוש (אנליטיקה)
כדי לשפר את המשחקים, כל טלפון שולח ל-[PostHog](https://posthog.com) אירועי שימוש אנונימיים: איזה משחקים מתחילים ומסיימים, כמה זמן הם לוקחים, איפה נוטשים, איך מגיעים (קישור הזמנה / ישירות), כמה זמן לוקח להתחבר. בלי שמות, בלי פתקים, בלי קודים סודיים ומילים, בלי עוגיות. דפדפן ששולח Global Privacy Control לא נמדד.
ההפעלה (מפתח הפרויקט), רשימת האירועים והדשבורדים המומלצים: [ANALYTICS.md](ANALYTICS.md).

## בדיקות
**לפני כל העלאה:** `tests/run-all.sh` (ועם `live` – גם מול האתר החי). מריץ את כל אלה:
```
node tests/logic.test.mjs                                  # חוקי המשחקים והסדרה: 60 סדרות אקראיות מלאות + קלט שגוי + כל X/O בתוך המשבצת
tests/with-servers.sh node tests/analytics.js              # אירועי האנליטיקה: מה נשלח, ושלא נשלחים שמות / קודים / מילים
tests/with-servers.sh node tests/turn-ui.js                # תורך / לא תורך, צלילים, השתקה, "איך משחקים" פעם אחת לכל משחק
tests/with-servers.sh node tests/interact.js               # כל לחיצה מסמנת בדיוק במקום, ושום דבר לא זז מתחת לאצבע
tests/with-servers.sh node tests/e2e-games.js              # סדרות שלמות דרך המסך, עם משחק חוזר וטעינות מחדש
MODE=relay  tests/with-servers.sh node tests/e2e-net.js    # 19 תרחישי נתק וחזרה – שרתי תיווך בלבד (כמו גלישה סלולרית)
MODE=both   tests/with-servers.sh node tests/e2e-net.js    # תיווך + קו ישיר   (יש גם MODE=half, MODE=direct)
tests/with-servers.sh node tests/e2e-outage.js             # שרתי התיווך נופלים וחוזרים באמצע משחק
tests/with-servers.sh node tests/visual.js                 # כל מסך ב-14 גדלי מסך: גלישה הצידה, טקסט חתוך, כפתורים קטנים, מצב התור
tests/with-servers.sh tests/webkit-all.sh                  # צילומי מסך ולחיצות במנוע WebKit (המנוע של דפדפני האייפון)
```
`tests/with-servers.sh` מרים שרת קבצים ושרת תיווך מקומי לזמן הבדיקה. צריך Playwright, ו-`npm i aedes ws websocket-stream`;
לבדיקת WebKit: `apt-get install gir1.2-webkit2-4.1 gir1.2-gtk-3.0 python3-gi python3-gi-cairo xvfb`.
מסכים לדוגמה בלי רשת: `?demo=five&me=0` (רשימת הסצנות ב-`js/demo.js`).
